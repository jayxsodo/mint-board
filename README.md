# Agent 打新 · 交互看板 (Mint Board)

面向 BSC (Binance Smart Chain) 代币发售、打新进度追踪与 PancakeSwap V2 交易辅助的单文件纯原生看板网页应用。

- **本地文件路径**: `~/agy-bridge/workdir/mint-board/index.html`
- **在线访问链接**: [https://jayxsodo.github.io/mint-board/](https://jayxsodo.github.io/mint-board/)
- **网络技术规范**: 零外部 CDN 依赖，纯原生 JavaScript 手写 JSON-RPC `eth_call` ABI 编码/解码与 Keccak-256 哈希引擎，杜绝网络封锁与 CDN 故障。
- **资金与安全声明**: **只写代码和发布网页，绝不连接/操作任何钱包去自动交易，不签名、不动钱。代码内绝无任何私钥、助记词字段或收集逻辑。页面内的卖出功能仅供委托方本人连接浏览器 Web3 钱包后亲自核实并签名。默认自带「模拟模式」开关且默认开启。**

## 一、界面与核心功能

### 1. 顶部栏 (Status & Watch Wallet)
- **观察钱包地址**: 默认填入 AW 钱包 `0x1E4Fe11535C8C97eae4226C1820e1C7457b8fB63`，支持手动修改并点击「更新」立即重查。
- **实时指标**:
  - 观察钱包 BNB 余额（实时 `eth_getBalance`）。
  - BSC 实时最新区块高度 + 当前 RPC 节点端到端延迟（毫秒）。
  - BNB 美元现价（基于 Pancake V2 WBNB/USDT 流动池储备毫秒级精确换算）。
- **钱包连接**: 点击「⚡ 连接钱包」唤起浏览器 Web3 钱包（如 MetaMask / Rabby），自动校验并引导切换至 BSC 主网（ChainID 56）。
- **刷新按钮**: 手动触发全量链上读数拉取。

### 2. 打新项目切换与管理
- **项目标签栏**: 预置主流项目，附带状态徽标（`未开盘` / `发售中` / `已开盘` / `已售罄` / `待手动更新`）。
- **快捷键支持**: 键盘直接按 `1` ~ `9` 毫秒级无缝切换不同项目。
- **自定义管理**:
  - 「➕ 添加项目」：弹窗自定义代币合约、发售合约、每份价格、每份代币数、总份数、税率、开售/截止时间、进度函数名等。
  - 「⚙️ 编辑此项目」/「删除项目」。
  - 「📤 导出」/「📥 导入」：全量项目配置可导出为 JSON 文件本地备份或随时还原，所有数据自动持久化于浏览器 `localStorage`。

### 3. 卡 A · 发售进度 (Presale Progress)
- **主视觉指标**:
  - 当前状态与开售时间（附「已开始」/「未开始」标签）。
  - 截止时间动态倒计时（天 / 时 / 分）。
  - 已售份数 / 总份数及彩色发光百分比进度条。
  - 距卖满剩余份数。
  - 基准价（每份价格 ÷ 每份代币数，BNB/枚）与每份规则说明。
- **链上实测函数**: 优先调用项目发售合约的视图函数读取链上真实已售进度。若合约不支持或未探通，自动提示并提供手动录入输入框（存入 `localStorage`），拒绝任何虚假官网宣传数据。

### 4. 卡 B · 价格与收益 (Pancake V2 Price & Returns)
- **流动池储备与现价**: 实时调用 Pancake V2 Factory `getPair` 与 Pair `getReserves` 获取储备，若无储备或未建池明确标识「无池/未开盘」。
- **收益倍数**:
  - **名义倍数**: 当前现价 ÷ 发售基准价。
  - **扣税净倍数**: 扣除该代币专属卖出税（`Sell Tax %`）后的真实到手倍数。
- **单份变现与浮盈**:
  - 1 份代币扣税后实际可换得的 BNB 与美元价值。
  - 池子储备结构（BNB 量 / 代币量）与开盘已持续时长。
  - 实时迷你走势图（Sparkline）与本会话涨跌幅。
  - 我的持有成本与未实现浮盈（BNB 及百分比）。
- **策略提示行 (提示非投资建议)**:
  - 净倍数 ≥ 1.5x：提示「已覆盖成本并具备稳健收益，可考虑卖出」。
  - 净倍数 ≥ 2.0x：提示「净倍数已达 2x+，可考虑先卖回本部分锁定利润」。
  - 净倍数 < 1.0x：提示「破发预警，流动性偏薄，注意风险」。

### 5. 卡 C · 卖出面板 (Sell Panel)
- **代币余额**: 实时读取观察钱包或已连接钱包的 ERC20 `balanceOf`。
- **快捷输入**: 数量输入框配合 `25%`、`50%`、`75%`、`100%` 快捷换算按钮。
- **滑点与路由报价**:
  - 默认滑点 12%（可自定义）。
  - 实时通过 Pancake V2 Router (`0x10ED43...`) 调用 `getAmountsOut` 获得最精准链上预估到手 BNB。
- **模拟模式 (安全机制)**:
  - **默认开启**。开启状态下点击「执行卖出」仅做全流程模拟计算并记录日志，绝不发链上交易。
- **真实卖出流程**:
  - 必须由委托方亲自连接钱包。
  - 弹出二次确认框，严格列明代币、卖出量、滑点、最少到手 BNB。
  - 严格校验 ERC20 `allowance`，若不足则引导发起 `approve`，随后执行 `swapExactTokensForETHSupportingFeeOnTransferTokens`（兼容带税代币）。
  - 最终签名必须在委托方本人的浏览器插件（MetaMask / Rabby）中人工确认。

### 6. 卡 D · 卖出机器人 (自动化策略监控)
- **策略参数**:
  - 阶梯止盈：支持多行规则（如：达到 2.0x 卖出 50%，达到 3.0x 卖出 25%，达到 5.0x 卖出 25%）。
  - 峰值回撤止盈：达到激活倍数（如 3.0x）后，从最高峰值回撤达设定位（如 15%）触发全卖。
  - 独立滑点与轮询间隔（默认 3000ms，下限 1000ms）。
- **触发机制**:
  - **默认动作**: 仅提醒（写入控制台日志 + 触发浏览器原生 Web Notification 弹窗 + 表格行高亮红色闪烁）。
  - **去卖出面板**: 一键将策略卖出量快捷填入卡 C，由委托方亲自点击并签名。
- **状态安全**: 机器人配置保存在本地 `localStorage`，页面刷新后所有机器人状态自动重置为 `已停止`，杜绝后台误报。
- **心跳监测**: 实时记录每次成功轮询时间，超过 90 秒未收到回包时自动标注红色「⚠️ 疑似卡住」。

### 7. 卡 E · 控制台日志 (Terminal Logs)
- 终端黑底风格实时输出，支持按 `价格监测`、`机器人动作`、`卖出操作`、`错误警告` 筛选。
- 价格轮询日志内置节流机制（同项目至少间隔 5 秒一条），避免刷屏。

## 三、网络与容错架构

1. **五节点自动轮换故障转移 (Failover)**:
   - `https://bsc-dataseed.bnbchain.org`
   - `https://bsc-dataseed1.defibit.io`
   - `https://bsc-dataseed1.ninicoin.io`
   - `https://bsc-rpc.publicnode.com`
   - `https://rpc.ankr.com/bsc`
   任一节点出现网络拥堵或超时（4000ms），系统静默切换至下一节点重试，保障面板高可用。
2. **后台标签节能与降频**:
   利用 `document.hidden` 监听标签页状态，当用户切到其他浏览器标签页时自动停止无意义的高频刷新，切回时立刻激活恢复。

## 四、已知限制与特别说明

1. **开盘持续时间近似值**:
   由于前端完全通过纯 RPC `eth_call` 运行且不依赖中心化 Graph/Index 后台，流动池开盘时长是以「本客户端首次在链上探测到池储备 > 0 的时间戳」为基准存储于 `localStorage` 进行近似计时。
2. **免密与非托管**:
   看板不设中心化数据库，无后端服务器参与，所有配置与缓存均存储在当前浏览器的 `localStorage` 中。若更换浏览器或清理缓存，请使用「📤 导出」导出的 JSON 进行迁移。
3. **PancakeSwap 卖出滑点**:
   带有卖出税（Fee on Transfer）的代币，若滑点设定低于代币本身的转账税率，Router 交易将会被链上 Revert。请确保在卡 C 的滑点输入框中填入大于代币税率的值（例如 2% 税建议滑点 ≥ 5%，3.5% 税建议滑点 ≥ 8%，默认预设 12% 可覆盖绝大多数场景）。
